# Legacy prototypes

Earlier versions of SerialA Monitor, kept for reference only. They are **not built or maintained**.

- `electron/` + `src/`: first prototype (Electron + React)
- `src-tauri/`: second prototype (Tauri)
- `test_*.js`: scratch scripts used while debugging the Electron build

The current product is the native Rust + egui app in [`../src-native`](../src-native).
